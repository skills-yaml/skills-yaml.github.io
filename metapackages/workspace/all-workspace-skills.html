Catalog / Metapackages

all-workspace-skills

20 skills from the workspace scope, installed together with one command. skm writes each skill into skills.yaml as its own entry, pinned to the version listed below.

Package
workspace/all-workspace-skills
Scope
workspace/
Skills
20

Add it to your project

skm add workspace/all-workspace-skills --kind bundle --dry-run

skm add workspace/all-workspace-skills --kind bundle --yes

The first command shows what would be added. The second adds it. Needs skm 0.7.0 or later.
