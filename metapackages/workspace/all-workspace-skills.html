all-workspace-skills

20 skills from the workspace scope, installed together with one command.

Packageworkspace/all-workspace-skills
Scopeworkspace/
Skills20

Add it to your project

Adding a metapackage requires skm 0.7.0 or later.

  1. Preview the change

    This command shows what would be added, without changing anything:

    skm add workspace/all-workspace-skills --kind bundle --dry-run

  2. Add the metapackage

    This command adds it:

    skm add workspace/all-workspace-skills --kind bundle --yes

skm writes each skill into skills.yaml as its own entry, pinned to the version listed below.
