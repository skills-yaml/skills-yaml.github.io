Put a skill folder where Antigravity or Gemini CLI can discover it, or attach it explicitly to an agent you build with Google’s Agent Development Kit.

Install and invoke a skill in Antigravity

Copy the entire skill folder into .agents/skills/ at your workspace root for a project skill, or into ~/.gemini/config/skills/ for a personal skill. The App and CLI also scan parent folders up to the repository root. Antigravity setup by surface

  2. Check for /release-notes in the interactive prompt. If you copied the folder during the session, run /skills reload or start a new conversation to refresh the slash commands. Antigravity CLI slash commands

Standalone Antigravity IDE

Discover and approve a skill in Gemini CLI

If your account still uses Gemini CLI, copy the whole folder to .agents/skills/release-notes/ at your workspace root, or choose another Gemini CLI location from the table. Run gemini from the project directory. On startup, Gemini CLI gives the agent the name and description of each enabled skill. Workspace copies take precedence over personal copies, then extension and built-in copies. Within the same scope, .agents/skills/ wins over .gemini/skills/ for the same name. Gemini CLI discovery and precedence

  1. Use /skills reload if the session was already open. Run /skills list and look for release-notes. Gemini CLI skill commands
  2. Ask Gemini to use the skill with the verification prompt below. When Gemini selects the skill, it calls activate_skill. Review the name, purpose and directory in the confirmation. Gemini CLI activation and consent
  3. Approve the expected skill and directory. The CLI loads the instructions and gives the agent read access to bundled files. The activation confirmation identifies which copy the agent selected. Compare the resulting draft with the expected output below. Gemini CLI resource access

Attach a skill to an ADK agent

Use Python ADK 1.25.0 or later. In an existing ADK project, put the folder at skills/release-notes/ next to the agent package’s agent.py. Load it from that module and attach the toolset to root_agent. For an existing agent, add the toolset to its current tools and keep its configured model. ADK SkillToolset setup

from pathlib import Path

from google.adk import Agent
from google.adk.skills import load_skill_from_dir
from google.adk.tools.skill_toolset import SkillToolset

skill_dir = Path(__file__).parent / "skills" / "release-notes"
release_notes = load_skill_from_dir(skill_dir)

root_agent = Agent(
    name="release_notes_agent",
    model="gemini-flash-latest",
    tools=[SkillToolset(skills=[release_notes])],
)
  1. With model credentials configured, run adk web from the directory containing the agent package. Open the printed URL and select the package in the agent dropdown. Start the ADK web interface
  2. Send the verification prompt below. SkillToolset exposes the skill metadata to the model, which calls load_skill to read the instructions for a matching task. ADK skill loading
  3. Inspect the run’s events for a successful load_skill call for release-notes, then compare the response with the expected draft. ADK web interface event history

Verify a release-notes draft

Try this sample after setup. In the Antigravity App or CLI, use /release-notes in place of the first sentence and include the three change notes.

Use the release-notes skill to draft release notes from these change notes.

- Confirmed: The activity log now offers CSV export.
- Confirmed: Fixed duplicate entries in the activity log after a refresh.
- Unverified: CSV export may be twice as fast as the previous internal prototype.

Expect a draft in the conversation with the export under Added and the duplicate-entry fix under Fixed. The speed claim belongs only under Needs confirmation. For the missing-input check, start a fresh conversation and invoke the skill without any change notes. Expect the agent to ask for the notes and wait.

Before enabling a shared skill, review the instructions and resources it can use. If the skill is missing or behaves differently across tools, check discovery, selection and execution.
