Use skills in Google developer tools

Put a skill folder where Antigravity or Gemini CLI can discover it, or attach it explicitly to an agent you build with Google’s Agent Development Kit.

Choose your Google developer tool

Product details checked November 27, 2026. Google set June 18, 2026 as the transition date from Gemini CLI to Antigravity CLI for free Gemini Code Assist for individuals and Google AI Pro and Ultra users. Google says Gemini CLI access continues through Gemini Code Assist Standard or Enterprise licenses and paid Gemini or Gemini Enterprise Agent Platform API keys.[1]

Use the release-notes/ folder from the first-skill tutorial. Keep name: release-notes and a description in SKILL.md so you can use the same file across these tools. ADK checks that the name matches the folder.[2]

Install and invoke a skill in Antigravity

Copy the entire skill folder into .agents/skills/ at your workspace root for a project skill, or into ~/.gemini/config/skills/ for a personal skill. The App and CLI also scan parent folders up to the repository root.[3]

Workspace path
.agents/skills/release-notes/SKILL.md

Antigravity App

  1. Open the project containing the skill and start a conversation in that project.
  2. In the message box, select /release-notes and send it with the sample change notes.[3]
  3. Check the draft against the expected output.

Antigravity CLI

  1. Run agy from the workspace directory. The CLI also discovers personal skills under ~/.gemini/antigravity-cli/skills/ and ~/.gemini/skills/. Use ~/.gemini/config/skills/ for a personal copy shared with the App.[3]
  2. Check for /release-notes in the interactive prompt. If you copied the folder during the session, run /skills reload or start a new conversation to refresh the slash commands.[3]
  3. Send /release-notes with the sample change notes and compare the response with the expected draft below.

Standalone Antigravity IDE

  1. Open your workspace in the standalone IDE. It also supports the legacy personal location at ~/.gemini/antigravity/skills/.[3]
  2. Open Customizations in the agent side panel and confirm that release-notes appears.[3]
  3. Send the verification prompt below, including the skill name. Check the draft against the expected output.

Discover and approve a skill in Gemini CLI

Copy the skill folder to .agents/skills/release-notes/ at your workspace root and run gemini from that directory. A workspace copy takes precedence over a personal, extension or built-in copy. Within the same scope, .agents/skills/ wins over .gemini/skills/ for a matching name.[4]

  1. Use /skills reload if the session was already open. Run /skills list and look for release-notes.
  2. Send the verification prompt below. When Gemini calls activate_skill, review the name, purpose and directory in the confirmation.[4]
  3. Approve the expected skill and directory. Approval loads the instructions and gives Gemini read access to bundled files. Check the draft against the expected output.

Attach a skill to an ADK agent

Use Python ADK 1.25.0 or later. Put skills/release-notes/ next to agent.py in your agent package. In an existing agent, append the toolset to tools and keep your configured model.[2]

agent.py
from pathlib import Path

from google.adk import Agent
from google.adk.skills import load_skill_from_dir
from google.adk.tools.skill_toolset import SkillToolset

skill_dir = Path(__file__).parent / "skills" / "release-notes"
release_notes = load_skill_from_dir(skill_dir)

root_agent = Agent(
    name="release_notes_agent",
    model="gemini-flash-latest",
    tools=[SkillToolset(skills=[release_notes])],
)
  1. With model credentials configured, run adk web from the directory containing the agent package. Open the printed URL and select the package in the agent dropdown.[5]
  2. Send the verification prompt. Inspect the run’s events for a successful load_skill call for release-notes, then check the draft against the expected output.[2]

Verify a release-notes draft

Try this sample after setup. In the Antigravity App or CLI, use /release-notes in place of the first sentence and include the three change notes.

Prompt
Use the release-notes skill to draft release notes from these change notes.

- Confirmed: The activity log now offers CSV export.
- Confirmed: Fixed duplicate entries in the activity log after a refresh.
- Unverified: CSV export may be twice as fast as the previous internal prototype.

Expect a draft in the conversation with the export under Added and the duplicate-entry fix under Fixed. The speed claim belongs only under Needs confirmation.

Start a fresh conversation and invoke the skill without any change notes. The agent should ask for the notes and wait.

Before enabling a shared skill, review the instructions and resources it can use. If the skill is missing or behaves differently across tools, check discovery, selection and execution.
