Agent Skills learning center

What are Agent Skills?

An Agent Skill is a folder of reusable instructions and optional resources. For weekly release notes, the skill holds your drafting procedure and each request supplies the latest changes.

A repeatable task with a consistent output

Every Friday, you turn a fresh set of change notes into a customer-facing draft. The changes vary each week, but the procedure stays the same. Group the user-facing changes, use plain language, flag unverified or breaking changes for review, and return a draft for the release owner.

An Agent Skill captures that procedure in a folder the agent can load for a matching task. Keep the rules, output format, and examples in the skill. Supply the current release’s notes with the request. The same skill can then guide the next draft when it’s available in the agent’s environment. Anthropic’s introduction to Agent Skills

What lives in a skill folder

The open Agent Skills specification requires SKILL.md. Its YAML frontmatter, enclosed by lines containing ---, has two required fields. The name matches the enclosing folder, such as release-notes. The description says what the skill does and when to use it. The Markdown body below the frontmatter holds the workflow, including how to handle missing input and what to return. Agent Skills file format

A text-only release-notes skill can start with that single file. As the workflow grows, the skill can point to a style guide in references/ and a draft template in assets/. The instructions tell the agent when to open each file using a path relative to the skill folder. Workflows that need executable helpers may add them in scripts/, subject to the host’s runtime and permissions. Agent Skills optional directories · File references

release-notes/
├── SKILL.md
├── references/
│   └── style-guide.md
└── assets/
    └── draft-template.md

How an agent finds and loads a skill

Suppose you ask, “Draft this week’s customer release notes. The activity log now offers CSV export, and refreshing the log no longer creates duplicate entries.” Agent Skills uses a staged loading pattern called progressive disclosure. Agent Skills specification on progressive disclosure

  1. Discover the metadata. The host, meaning the application or runtime that runs the agent, makes the names and descriptions of available skills visible. The release-notes description identifies requests to draft a release note or changelog entry from supplied changes.
  2. Activate the skill. A host may match your request against that description or let you select the skill explicitly. On activation the agent reads the full SKILL.md instructions. In this example, the CSV export goes under “Added” and the duplicate-entry fix goes under “Fixed.”
  3. Open resources as needed. If the instructions call for checking the product’s terminology, the agent opens references/style-guide.md. It uses the supplied changes as evidence and returns a draft in the conversation for the release owner to review.

Setup and selection depend on the host. Follow the guide for Claude, Google developer tools, or Codex, ChatGPT and the OpenAI API.

Choose the right mechanism

Prompt
Give instructions for the task in front of you. Ask for a shorter opening paragraph or supply the changes for this week’s release.
Project instructions
Set guidance that applies across work in a project, such as the product name and house style for customer-facing copy. The file and when it loads depend on the host. Claude Code project instructions · Codex project instructions
Skill
Save a procedure that applies to requests of a particular kind. The release-notes skill can use the project’s house style and follow its own rules for grouping changes and flagging uncertainty. Anthropic’s Agent Skills overview
Connector
Connect the host to a particular service, such as the issue tracker. A connector is the integration that gives the agent access to that service’s data or actions within its permissions. It may use MCP to expose a tool for fetching completed tickets. The skill can then guide the agent through drafting from the results. OpenAI on combining skills and server tools
Model Context Protocol (MCP)
MCP is an open protocol for connecting AI applications to tools, data, and other capabilities. If an issue tracker integration uses MCP, the MCP server exposes the available capabilities and the protocol defines how the host communicates with it. Model Context Protocol introduction
Plugin
Install components together in a host that supports plugins. A release workflow plugin could package the drafting skill and a configuration for the issue tracker’s MCP server. OpenAI plugin architecture

The host and connected service determine which tools and data the agent can access. Drafting from pasted notes works with the skill alone. If the workflow starts reading a tracker, review the skill and its access before enabling it.

Read the Skills Directory guide with its limits in mind

Skills Directory illustrates focused workflows, staged loading, and the role of MCP. Its descriptions of memory, resource limits, and portability need qualification. What Are Claude Skills? from Skills Directory

  • Persistence. A skill makes saved instructions and resources available in later sessions when the host loads them. For the release-notes workflow, each run still needs the changes for that release. Products can offer separate features that store information across sessions. Anthropic’s Agent Skills overview · Claude Code memory
  • Resource limits. Loading reference files on demand reduces what the host loads up front. Once the agent reads a file, its contents use available context, and scripts run within the host’s runtime limits. Agent Skills specification on staged loading
  • Portability. The shared format helps you reuse the folder in hosts that support it. Installation, invocation, permissions, and the availability of tools or script runtimes still depend on the destination. Test the workflow there. Port and troubleshoot a skill

The directory’s format guide also shows top-level fields such as version and requires. For a portable skill, use the specification’s field list. Its optional metadata mapping can hold a version string, and compatibility can describe environment requirements. Skills Directory format guide · Agent Skills frontmatter specification

Decide what to save for next week

If you only need to rewrite one draft, paste it into a prompt with the changes you want. If you’ll draft release notes every week from supplied material, save the recurring procedure as a skill and keep the weekly changes in each request. If you also want the agent to fetch change history, give it access to the tracker through a connector or another tool supported by the host, then define how the drafting workflow uses those records.
