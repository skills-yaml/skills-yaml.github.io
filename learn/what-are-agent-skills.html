Agent Skills learning center

What are Agent Skills?

An Agent Skill is a folder of reusable instructions and optional resources. For weekly release notes, the skill holds your drafting procedure and each request supplies the latest changes.

A repeatable task with a consistent output

Every Friday, turn a fresh set of changes into a customer-facing draft. Group the confirmed changes, use plain language, and flag anything that still needs checking.

Save those steps and the draft format in a skill called release-notes. When you ask for the next draft, give the agent that week’s changes.

What lives in a skill folder

Start with release-notes/SKILL.md. Put the name and description in a YAML header between two lines of three dashes. Use release-notes as the name and say in the description that the skill drafts release notes or changelog entries from supplied changes. Write the steps in Markdown below the header.[1]

Add a style guide in references/ or a draft template in assets/ when you need one. In SKILL.md, say when to open each file and give its path from the skill folder. You can also put helpers in scripts/ if the agent can run them.[2]

Skill folder
release-notes/
├── SKILL.md
├── references/
│   └── style-guide.md
└── assets/
    └── draft-template.md

How an agent finds and loads a skill

Ask for a draft from two confirmed changes. The activity log now offers CSV export, and a refresh no longer creates duplicate entries. The agent can load the skill in three stages. This is called progressive disclosure.[3]

  1. Discovery. The agent sees the names and descriptions of available skills. Your request matches the description for release-notes.
  2. Activation. Once the skill is selected, the agent reads SKILL.md. The steps put the CSV export under “Added” and the duplicate-entry fix under “Fixed.”
  3. Resources. If a step calls for checking product terminology, the agent opens references/style-guide.md. It returns the draft for the release owner to review.

Setup and selection vary by product. Follow the guide for Claude, Google developer tools, or Codex, ChatGPT and the OpenAI API.

Choose the right mechanism

Prompt
Supply this week’s changes or ask for a shorter draft.
Project instructions
Save guidance for work across the project, such as which product names to use in customer-facing copy.[4]
Skill
Save the steps you repeat each week, including how to group changes and flag claims for review.
Connector
Connect a specific service, such as your issue tracker. With the right permissions, the connector can give the agent a tool to fetch completed tickets.[5]
Model Context Protocol (MCP)
Use this open protocol to connect AI applications to tools and data. An issue tracker connector can use MCP to expose tools through a server. The protocol defines how the application and server communicate.[6]
Plugin
Install related components together. A plugin could package the release-notes skill with the tracker’s MCP server configuration.[7]

Read the Skills Directory guide with its limits in mind

Skills Directory describes skills as lasting memory, calls reference capacity unlimited, and says one skill works across platforms.[8]

  • Memory. The saved skill carries your drafting steps into later sessions where it’s available. Give it the current changes each time. Claude Code’s auto memory is a separate feature.[4]
  • Resources. A bundled reference uses context when the agent reads it. Open only the files needed for the draft and keep those files short enough to use.[3]
  • Portability. You can reuse the skill folder in another agent that supports it. Check that agent’s installation steps, invocation, permissions, and tool support. Claude Code, for example, documents which frontmatter options are specific to it.[9]

Decide what to save for next week

For a one-off draft, put the changes and instructions in a prompt. For a weekly draft, put the steps in the skill and paste the latest changes each time.

If you later need to fetch changes from a tracker, give the agent access through a connector and tell the skill which records to use. Review the skill and its access before enabling it.
