Agent Skills learning center

An Agent Skill is a folder of reusable instructions and optional resources. Its SKILL.md file describes when to use the skill and how to carry out the task.

For your first run, write a skill that drafts release notes, choose one host to try it in, then evaluate it with sample requests.

Installing a skill someone else wrote? Review the skill before you install it.

Publish through skills-yaml

Once you’ve tested a skill you want to share, the skills-yaml registry lets projects install a specific release using skm. Pin a version when teammates or CI need to use the same tested release until you choose to upgrade.

Follow the registry guide to publish a skill package, or browse the catalog to see what is available.
